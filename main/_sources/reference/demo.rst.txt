Demo Code
=========

Example code that uses the MCIWB library. These are the best worked examples
of how to build with mciwb. The source is in
`src/mciwb/demo <https://github.com/gilesknap/mciwb/tree/main/src/mciwb/demo>`_.

In ``mciwb shell`` import a demo with e.g.
``from mciwb.demo.pagoda import build_pagoda``.
